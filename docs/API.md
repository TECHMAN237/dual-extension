# Backend API

Base URL: `http://localhost:8787` (local) or your Render URL. All bodies are JSON. Errors use the envelope `{ "error": { "code", "message", "details?" } }`.

Headers sent by the extension:

| Header | Required | Purpose |
| --- | --- | --- |
| `Content-Type: application/json` | for POST/PUT | — |
| `X-Douala-Client-Id` | recommended | Random, anonymous id generated by the extension (8–64 chars `[A-Za-z0-9_-]`). Used for rate limiting, history and correction ownership. |
| `X-Douala-Client-Token` | only when `EXTENSION_ACCESS_TOKEN` is set | Shared client token (not an AI secret). |
| `X-Admin-Token` (or `Authorization: Bearer`) | admin routes | `ADMIN_API_TOKEN`. Without a token configured, admin routes answer only from localhost. |

Rate limit: `RATE_LIMIT_MAX` requests per `RATE_LIMIT_WINDOW_MS` per IP+client id (default 60/min). `/api/health` is exempt. Body limit: `MAX_BODY_BYTES` (256 KB).

## Public endpoints

### `GET /api/health`
```json
{ "status": "ok", "version": "0.1.0", "provider": "anthropic", "model": "claude-opus-5-5", "mock": false, "storage": "memory", "knowledgeEntries": 48, "uptimeSeconds": 12 }
```

### `GET /api/languages`
`{ "languages": LanguageDefinition[], "limits": LIMITS }`.

### `POST /api/scan/analyze`
Request: `{ "domain"?, "htmlLang"?, "sampleText": string (≤5000), "segmentCount": number }`
Response: `{ "detectedLanguage": "en"|"fr"|null, "confidence": "high"|"medium"|"low", "supported": boolean, "message": string|null }`

### `POST /api/translate/batch`
Request:
```json
{ "sourceLanguage": "auto", "targetLanguage": "dua", "domain": "example.com",
  "items": [ { "id": "d-1", "text": "Sign in", "context": "button" } ] }
```
Constraints: 1–60 items, ≤20,000 characters total, ≤2,000 per item, unique ids. `context` ∈ `heading, paragraph, button, link, navigation, list_item, label, placeholder, title_attribute, alt_text, aria_label, table_cell, form_description, other`.

Response:
```json
{ "sourceLanguage": "en", "targetLanguage": "dua",
  "detectedLanguage": { "language": "en", "confidence": "high" },
  "results": [ {
      "id": "d-1", "sourceText": "Sign in", "translatedText": "…" ,
      "status": "translated",          // translated | uncertain | skipped | error
      "evidence": "high",              // high | moderate | low | unverified
      "needsReview": false,
      "references": [ { "id": "…", "category": "expression", "sourceText": "Sign in", "targetText": "…", "sourceName": "…", "sourceUrl": "…", "reference": "p. 12", "origin": "verified_source", "validationStatus": "verified", "reliability": "academic" } ],
      "note": null, "cached": false } ],
  "provider": "anthropic", "model": "claude-opus-5-5", "mock": false, "historyId": "…" }
```
Semantics: `uncertain` = the engine declined for lack of evidence (keep the original); `skipped` = untranslatable (URL, number, identifier); `error` = provider failure for this item (the HTTP status is still 200 so partial results are usable). Provider-level failures never leak keys; the `note` carries a safe message.

### `POST /api/translate`
Single segment: `{ "sourceLanguage", "targetLanguage", "text", "context", "domain" }` → same envelope with `result` instead of `results`.

### `POST /api/corrections` → `201`
Request: `{ "sourceLanguage", "targetLanguage", "sourceText", "aiTranslation": string|null, "proposedTranslation", "explanation"?, "context", "domain"?, "clientId" }`
Response: `CorrectionRecord` `{ "id", "status": "pending", "reviewNote": null, "createdAt", … }`. Quota: 200 submissions per client per 24 h.

### `GET /api/corrections/status?ids=a,b,c` (or no ids → all corrections of the calling client)
`{ "corrections": CorrectionRecord[] }` with `status` ∈ `pending | approved | rejected`.

### `GET /api/history`
`{ "history": [ { "id", "domain", "sourceLanguage", "targetLanguage", "translatedCount", "uncertainCount", "status", "createdAt" } ] }` for the calling client (last 50).

### `GET /api/knowledge/search?q=…&sourceLanguage=en&limit=10&includeUnverified=true`
`{ "query", "sourceLanguage", "references": [ TranslationReference & { "relevance": 0.93, "matchType": "exact" } ] }`

## Administrative endpoints (token protected)

| Method & path | Purpose |
| --- | --- |
| `GET /api/admin/overview` | Counts, provider, storage, cache size, 7-day usage |
| `GET /api/admin/sources` / `PUT /api/admin/sources/:id` | List / register linguistic sources (`LinguisticSource` body) |
| `GET /api/admin/knowledge?status=pending&sourceId=&limit=&offset=` | Browse knowledge entries |
| `POST /api/knowledge/ingest` | Manual import: `{ "sourceId", "entries": [ { "sourceLanguage", "sourceText", "targetText", "category", "context", "example", "note", "reference", "validationStatus", "tags" } ] }` → `201 { ingested, entries }` |
| `POST /api/admin/ingest/url` | Polite fetch + extraction: `{ "sourceId", "url", "sourceLanguage", "format"?, "dryRun"?, "html": { "strategy", "sourceColumn", "targetColumn", "entrySelector", "headwordSelector", "glossSelector" } }` → ingestion report |
| `POST /api/admin/knowledge/:id/review` | `{ "status": "verified"|"rejected"|"pending", "note"? }` |
| `GET /api/admin/corrections?status=pending` | Review queue |
| `POST /api/admin/corrections/:id/review` | `{ "decision": "approved"|"rejected", "note"?, "reviewer"? }`. Approval creates a verified `user_correction` knowledge entry and clears the cache. |
| `GET /api/admin/usage?days=7` | Usage summary by model |

The admin page at `/admin/` is a thin client over these endpoints.

## Status codes

`200` ok · `201` created · `400` validation error (Zod issues in `details`) · `401` missing/invalid token · `403` admin from non-localhost without token · `404` unknown route or entity · `413` body too large · `415` wrong content type · `429` rate limited / correction quota · `503` provider not configured · `500` internal (no details leaked).
